게임 파일(약 55MB)을 불러오는 중입니다. 처음 한 번은 시간이 걸릴 수 있습니다.

플레이 전에 알아 두실 점

원본(PC 빌드)과 같은 게임을 WebGL로 빌드했습니다. 플레이 전에 아래 내용을 참고해 주세요.

  • 플레이 모드

    웹에서는 [싱글 플레이]로

    원래는 서버에 접속해 여럿이 함께하는 멀티플레이 게임입니다. 통신은 .NET 기반 웹소켓으로 짜여 있어, 웹에서 쓰려면 JS 라이브러리 기반 웹소켓으로 바꿔야 합니다. 그러면 원본 코드를 고쳐야 하고 원본 게임과 달라질 수 있어, 웹 버전은 [싱글 플레이]로 변경하여 원본 게임과 동일한 환경을 유지했습니다.

  • 화면

    [화면 크기]·[전체화면]은 위쪽에서

    화면 크기는 위쪽 [화면 크기]에서 바꿉니다. [전체화면]을 누르면 게임이 화면을 채우고, Esc로 빠져나옵니다.

  • 조작

    한 번 클릭하고 시작

    게임 화면을 한 번 클릭한 뒤 조작해 주세요. PC 브라우저(Chrome·Edge)를 권장합니다.

  • 종료

    [나가기]를 누르면 게임이 멈춤

    웹에서는 메인 메뉴의 [나가기]를 누르면 게임이 멈춥니다. 다시 하려면 페이지를 새로고침(F5)해 주세요.
